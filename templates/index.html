Command Reference
Type help in terminal for full guide with examples
── UK / AU Mode ──
region uk|au Switch mode
pdf <path> Load FBA label PDF
csv <path> Load packing list
range add s e [t] Add label range
range list List all ranges
range clear Clear ranges
process Run UK/AU splitting
── US Mode ──
region us Switch to US mode
us-pdf <path> Load US SKU PDF
us-grid r c Grid: rows x cols
us-margin L T R B Page margins (pt)
us-process Run SKU splitting
── Output ──
download List generated files
download <name> Get a specific file
download-all Get all as ZIP
── General ──
help Full command reference
status | info Show current state
history Command history
clear Clear terminal
All file paths must be absolute.
